📖 Clash订阅导入教程

Windows / Mac 用户（Clash for Windows / ClashX）

  1. 在机场官网购买套餐后，进入用户中心，找到"订阅链接"或"Clash订阅"
  2. 复制Clash订阅链接（通常以 https:// 开头）
  3. 打开Clash客户端，找到"Profiles"（配置）或"订阅"页面
  4. 点击"从URL下载"或"Download from URL"，粘贴订阅链接
  5. 点击"下载"，等待节点列表更新完成
  6. 在主界面选择代理模式（推荐"规则模式"），开启系统代理即可使用

Android 用户（Clash for Android）

  1. 复制机场提供的Clash订阅链接
  2. 打开Clash for Android应用
  3. 点击顶部"配置"选项卡
  4. 点击右上角"+"号，选择"URL"
  5. 粘贴订阅链接，输入配置名称（如"我的机场"）
  6. 点击保存，等待自动下载节点
  7. 返回主界面，点击开关启动Clash即可
⚠️ 订阅链接安全提示 订阅链接包含你的账户信息，不要分享给他人。建议定期在机场后台重置订阅链接。如果Clash客户端提示"订阅更新失败"，检查链接是否过期或账户是否到期。

❓ Clash机场常见问题

Clash订阅链接多久更新一次？▼
大多数机场的Clash订阅支持自动更新节点。在Clash客户端中可以设置自动更新间隔（推荐12小时或24小时一次）。当机场新增节点或维护节点时，订阅会自动同步最新的节点列表，无需手动操作。
Clash提示"All proxies are unavailable"怎么办？▼
这通常表示所有节点不可用。解决方法：1) 更新订阅链接获取最新节点；2) 检查机场套餐是否到期；3) 尝试切换不同节点；4) 检查本地防火墙/杀毒软件是否拦截Clash；5) 联系机场客服确认节点状态。
Clash规则模式和全局模式有什么区别？▼
规则模式（推荐）：根据内置规则自动分流，国内网站直连，国外网站走代理，速度快且省流量。全局模式：所有流量都走代理，访问国内网站会变慢。直连模式：关闭代理，所有流量直连。日常使用推荐规则模式。
Clash可以同时导入多个机场订阅吗？▼
可以。在Clash中可以添加多个订阅配置，通过切换不同的Profile来使用不同机场的节点。推荐保留1-2个备用机场，当主力机场故障时可以快速切换，保证科学上网的连续性。
