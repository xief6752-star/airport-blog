💻 Windows 配置教程

方法一：Clash Verge（推荐）

第1步：下载并安装

  1. 访问 Clash Verge GitHub 发布页面（github.com/clash-verge-rev/clash-verge-rev）
  2. 下载最新版本的 Clash.Verge_x64_setup.exe
  3. 双击运行安装程序，按提示完成安装
  4. 如果 Windows Defender 提示，选择"仍要运行"

第2步：导入订阅

  1. 打开 Clash Verge，点击左侧 订阅 图标
  2. 点击右上角 新建 按钮
  3. 选择 导入，类型选择 URL
  4. 粘贴你的机场订阅链接，点击 导入
  5. 等待下载完成，订阅会自动激活

第3步：配置代理模式

  1. 点击左侧 代理 图标
  2. 在代理模式中选择 规则（Rule）模式
  3. 在节点列表中选择一个节点
  4. 点击节点旁的延迟图标可以测速选择最快节点

第4步：启动代理

  1. 点击主界面的 系统代理 开关
  2. 确保开关变为绿色（已启用）
  3. 打开浏览器访问 google.com 测试是否成功

方法二：Clash Party

Clash Party 是另一个优秀的 Windows Clash 客户端，界面简洁，操作步骤与 Clash Verge 类似。访问 github.com/clashparty/clashparty 下载使用。

方法二：V2RayN

第1步：下载并安装

  1. 访问 V2RayN GitHub 发布页面
  2. 下载 v2rayN-With-Core.zip（包含核心）
  3. 解压到任意文件夹（建议英文路径）
  4. 运行 v2rayN.exe

第2步：导入订阅

  1. 右键点击托盘图标，选择 订阅分组 → 订阅设置
  2. 点击 添加 按钮
  3. 粘贴订阅链接，填写备注名称，点击 确定
  4. 点击 更新订阅 按钮

第3步：启动代理

  1. 在服务器列表中双击选择一个节点
  2. 右键托盘图标，选择 系统代理 → 自动配置系统代理
  3. 确保 路由设置 为 绕过大陆

🍎 macOS 配置教程

方法一：ClashX（推荐）

第1步：下载并安装

  1. 访问 ClashX GitHub 发布页面
  2. 下载 ClashX.dmg
  3. 打开 dmg 文件，将 ClashX 拖入 Applications 文件夹
  4. 首次运行时，在 系统偏好设置 → 安全性与隐私 中允许运行

第2步：导入订阅

  1. 点击菜单栏 ClashX 图标
  2. 选择 配置 → 托管配置 → 管理
  3. 点击左下角 + 按钮
  4. 粘贴订阅链接和名称，点击 确定

第3步：启动代理

  1. 点击菜单栏 ClashX 图标
  2. 打开 设置为系统代理
  3. 在 出站模式 中选择 规则判断
  4. 在 Proxy 中选择节点

📱 Android 配置教程

Clash for Android（推荐）

第1步：下载并安装

  1. 从机场官网或 GitHub 下载 Clash for Android APK
  2. 允许安装未知来源应用（设置中开启）
  3. 安装 APK 文件

第2步：导入订阅

  1. 打开 Clash for Android
  2. 点击顶部 配置 标签
  3. 点击右上角 + 按钮
  4. 选择 URL，粘贴订阅链接
  5. 点击右上角保存图标

第3步：启动代理

  1. 点击顶部 代理 标签
  2. 选择一个节点（可以点击闪电图标测速）
  3. 返回首页，点击中间开关启动代理
  4. 首次启动会提示创建 VPN 连接，点击允许

📱 iOS 配置教程

Shadowrocket（小火箭）

第1步：购买并下载

  1. 需要美区 Apple ID 账号
  2. 在 App Store 搜索 Shadowrocket（$2.99）
  3. 购买并下载安装
  4. 也可以购买共享美区账号下载（淘宝/闲鱼约 ¥10）

第2步：导入订阅

  1. 打开 Shadowrocket
  2. 点击右上角 + 按钮
  3. 类型选择 Subscribe
  4. 粘贴订阅链接到 URL 框
  5. 点击 完成

第3步：启动代理

  1. 在节点列表中点击延迟测试（闪电图标）
  2. 选择延迟最低的节点
  3. 返回首页，点击顶部开关
  4. 点击 允许 添加 VPN 配置

❓ 常见问题（FAQ）

Q1: Clash 和 V2Ray 哪个更好？

A: Clash 界面更友好，规则分流更方便，推荐新手使用。V2Ray 功能更强大，支持更多协议和自定义配置，适合进阶用户。两者都能满足日常使用，选择自己喜欢的即可。

Q2: 规则模式和全局模式有什么区别？

A: 规则模式（推荐）：根据规则自动判断，国内网站直连，国外网站走代理，省流量且速度快。全局模式：所有流量都走代理，适合需要更换 IP 的场景，但会浪费流量。

Q3: 订阅更新后节点消失了怎么办？

A: 1) 检查机场是否欠费或流量用完；2) 检查订阅链接是否正确；3) 尝试删除旧配置重新导入；4) 联系机场客服确认账号状态。

Q4: 如何选择最快的节点？

A: 1) 使用客户端内置的延迟测试功能（闪电图标）；2) 优先选择延迟低于 100ms 的节点；3) 测试节点实际速度（看 YouTube 视频是否流畅）；4) 晚高峰时段可能需要切换节点。

Q5: 为什么连上代理后还是打不开 Google？

A: 1) 确认客户端已启动（开关打开）；2) 确认选择了正常的节点；3) 检查系统代理是否已开启；4) 尝试更换其他节点；5) 重启客户端或重启设备。

Q6: 可以同时在多个设备上使用吗？

A: 大部分机场支持同时在 2-5 个设备使用（具体看套餐说明）。在多个设备上导入同一个订阅链接即可。但不建议分享给其他人使用，可能违反机场规则。
