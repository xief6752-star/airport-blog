🖥️ macOS 教程

ClashX Meta 详细配置教程

适用于 macOS 11+，菜单栏常驻，轻量好用，支持快速切换节点

ClashX Meta macOS 11+ 免费开源 难度：★☆☆ 简单

目录

① 下载安装② 导入订阅③ 选择节点④ 设置代理⑤ 验证常见问题

1
下载并安装 ClashX Meta

前往 GitHub 下载最新版本：

github.com/MetaCubeX/ClashX.Meta/releases

下载 ClashX.Meta.dmg 文件，打开后将 ClashX Meta 拖入「应用程序」文件夹。

🖼️
DMG 安装界面截图

首次运行时，macOS 会提示「无法验证开发者」，前往「系统设置 → 隐私与安全性」，点击「仍然打开」即可。

⚠️ 注意M1/M2/M3 芯片 Mac 请下载 arm64 版本；Intel Mac 请下载 x64 版本。

2
导入机场订阅

ClashX Meta 安装后会在菜单栏出现一个图标（猫咪 🐱 或 Clash 标志）。

点击菜单栏图标 → 「配置」→「托管配置」→「管理」，在弹出窗口中点击 「+」→「添加」。

🖼️
托管配置管理界面截图

在 URL 栏粘贴机场订阅链接，备注填写名称，点击「确认」。ClashX Meta 会自动下载并解析节点。

3
选择节点与代理模式

点击菜单栏图标 → 「Proxy」，展开后可以看到所有节点分组。

推荐选择 「规则」 模式（Rule）：国内流量直连、国外走代理，日常使用最佳。

🖼️
节点选择菜单截图
💡 提示在节点上点击「Benchmark」可测速，自动选择最快节点。

4
开启系统代理

点击菜单栏图标 → 勾选 「设置为系统代理」，打开后菜单栏图标会变为彩色，表示代理已激活。

开启后，Safari、Chrome、Finder 等系统应用的网络请求会自动走代理。

💡 开机自启在菜单栏 → 「其他设置」→ 开启「开机启动」，方便每次开机自动连接。

5
验证连接成功

打开 Safari 或 Chrome 访问 google.com，能正常显示则配置成功。

✅ 成功能正常打开 Google、YouTube，并能流畅播放视频。

❓ 常见问题

Q：macOS 提示「文件已损坏，无法打开」？
A：在终端运行：sudo xattr -rd com.apple.quarantine /Applications/ClashX\ Meta.app 然后重新打开。

Q：Terminal / IDE 无法走代理？
A：ClashX Meta 默认不代理终端流量，需在终端手动设置：export https_proxy=http://127.0.0.1:7890

Q：切换节点后速度没有变化？
A：关闭系统代理，等待 3 秒后重新开启，强制刷新连接。
