Cursor 编辑器中转 API 配置指南

彻底告别 Pro 订阅限流，以超低成本调用满血 Claude 3.5 & DeepSeek V3

适用工具：Cursor 支持系统：Win/Mac/Linux 难度：★☆☆ 简单

配置目录

① 准备工作 ② 打开设置 ③ 覆盖 OpenAI 路由 ④ 激活自定义模型 ⑤ 测试与验证 ⚠️ 常见排错

1
配置前的准备工作

在进行配置前，您需要从您所信任的中转站（如我们的合作伙伴：4ksAPI 或 硅基流动）后台获取以下两个关键凭证：

  1. API Key： 格式通常为 sk- 开头的一长串乱码。
  2. 接口代理地址 (Endpoint)： 例如 https://api.4ksapi.com/v1（特别提醒：必须以 https:// 开头，且末尾千万不要漏掉 /v1）。

2
打开 Cursor 的“模型设置”面板

① 启动您的 Cursor 编辑器。

② 点击编辑器右上角的 “齿轮图标 (Settings)”（在 Mac 上也可按下键盘快捷键 Cmd + ,，Windows/Linux 上按下 Ctrl + ,）。

③ 在弹出的设置菜单中，选择左侧导航栏的 “Models (模型)” 选项卡。

3
配置 OpenAI 自定义中转通道（核心步骤）

绝大部分中转 API 虽然支持非 OpenAI 模型（如 Claude 3.5），但在接口协议上它们是完全兼容标准 OpenAI 格式的。因此，我们只需要通过改写 OpenAI 的请求路由来完成全部模型的配置。

① 在“Models”界面中，找到 “OpenAI API Key” 选项。

② 将右侧的开关切换为 “已启用 (ON)”。

③ 在 “OpenAI API Key” 输入框中，填入您的中转 API 密钥。

④ 点击下方的 “Configure (配置)” 或 “Override (覆盖)” 展开高级选项。

⑤ 在 “Override OpenAI Base URL (覆盖 OpenAI API 代理地址)” 输入框中，准确填入刚才获取的代理地址，例如：https://api.4ksapi.com/v1。

⑥ 点击 “Save (保存)” 确认修改。

4
激活并添加您需要使用的自定义模型

由于中转站支持的模型极其丰富，而 Cursor 默认只展示官方内置的几个型号，我们需要手动添加对应模型的映射代号：

① 在“Models”界面的下方，找到 “Model Names (自定义模型名称)” 区域。

② 点击 “+ Add Model (添加模型)” 按钮。

③ 输入对应的模型代号，并点击右侧开关启用。常用大模型代号推荐：

  • claude-3-5-sonnet（调用顶级代码大模型）
  • deepseek-chat（代表满血版的 DeepSeek V3 核心模型，无敌性价比）
  • gpt-4o（日常重度逻辑任务）
⚠️ 关键一步添加完成后，请将 Cursor 默认自带的其他官方通道（如原生 Anthropic 或 Google 选项）全部关闭 (OFF)，以确保所有的请求都会被强制路由至我们配置的自定义中转节点。

5
测试与验证

① 回到 Cursor 编辑器界面，打开任何一个代码文件。

② 按下键盘快捷键 Cmd + L (Mac) 或 Ctrl + L (Windows) 调出 Chat 聊天侧边栏。

③ 在下方的模型下拉菜单中，选择我们刚才添加的 claude-3-5-sonnet 或 deepseek-chat。

④ 输入任意问题（例如：“用 Go 语言写一个并发的 Map 数据结构”），观察模型是否能够极速响应并生成流畅的代码。如果输出正常，说明配置已经完美通畅！

⚠️ 常见排错与小贴士

Q：报错 404 (Model Not Found)？
A：① 检查您的中转 API 代理地址末尾是否漏掉了 /v1；② 确认您的中转站账户内余额是否充足，部分中转站在欠费时会直接返回 404/403。

Q：Cursor Tab (自动补全) 无法使用？
A：接入自定义 API 后，Cursor 的 Tab 自动补全功能（Cursor Tab Copilot）可能无法工作，因为该功能依赖官方底层专有流。不过，中转 API 能够完美支持 Chat 聊天、Composer 多文件编辑以及快捷键代码修改，已经能覆盖 95% 以上的高阶 AI 编码场景！
