📖 使用教程

各平台客户端配置指南

图文详解，从零开始，10分钟搞定订阅导入与分流配置

🪟
Windows · Clash Verge Rev
最主流的 Windows 客户端，界面简洁，支持规则分流，适合大多数用户。
1
前往 GitHub 下载最新版 Clash Verge Rev
2
安装完成后，点击左侧 「订阅」 菜单
3
粘贴机场提供的 订阅链接，点击更新
4
切换到 「代理」，选择合适节点，开启系统代理
📄 查看详细图文教程 →
🍎
iOS · Shadowrocket
小火箭，iOS 最流行的代理工具，需使用美区/港区 Apple ID 购买（$2.99）。
1
切换到 美区 Apple ID，在 App Store 购买 Shadowrocket
2
打开 App，点击右上角 「+」 添加订阅
3
类型选择 Subscribe，粘贴机场订阅链接
4
首页开启 连接，选择全局或规则模式
📄 查看详细图文教程 →
🤖
Android · NekoBox
支持多种协议，开源免费，是 Android 上支持 Hysteria2 协议最好的客户端之一。
1
GitHub 下载 NekoBox APK 并安装
2
点击右上角菜单 → 「从剪贴板导入」
3
或选择 「订阅」 添加机场链接并更新
4
选中节点，点击右下角 ▶ 按钮 启动
📄 查看详细图文教程 →
🖥️
macOS · ClashX Meta
Mac 上轻量好用的代理工具，菜单栏常驻，支持快速切换节点和模式。
1
下载并安装 ClashX Meta（非 Rosetta 版）
2
点击菜单栏图标 → 「配置」→「托管配置」→「管理」
3
添加机场订阅链接，点击 「更新」
4
开启 「设置为系统代理」，选择节点
📄 查看详细图文教程 →
🍎
iOS · ClashMi
ClashMi 是 iOS 上新兴的 Clash 内核客户端，免费下载，界面现代，支持 Hysteria2、VLESS 等新协议，无需购买即可使用。
1
在 App Store 搜索 ClashMi 并免费下载安装
2
打开 App，点击底部 「订阅」 → 右上角 「+」
3
选择 「从 URL 导入」，粘贴机场订阅链接，点击确认
4
回到首页，开启 「VPN」 开关，选择规则模式即可使用
📄 查看详细图文教程 →
🎉
iOS / Android · ClashParty
ClashParty 是跨平台 Clash 客户端，iOS 和 Android 均可使用，支持一键导入订阅，界面简洁友好，适合新手快速上手。
1
iOS 在 App Store 搜索 / Android 在 GitHub 下载 ClashParty
2
打开 App，进入 「配置」 页面，点击右上角 「+」
3
选择 「URL 订阅」，粘贴机场提供的订阅链接并保存
4
返回主页，点击 「启动」，选择合适节点开始使用

Cursor · AI编程编辑器配置
Cursor 是目前最强的 AI 代码编辑器。教您如何完美配置第三方自定义中转 API 密钥，告别 $20/月订阅与限流限制，超低成本畅快编程。
1
打开 Cursor 设置 → Models 选项卡
2

在 Override OpenAI Base URL 中填入 中转代理地址

🛠️ 配置答疑

常见问题快速解决

90% 的新手问题都在这里

🔴

节点全部显示红色/连不上

① 检查订阅是否已更新（点击「更新订阅」）
② 尝试切换代理模式为「全局」
③ 确认机场账号未欠费/流量已用尽

🐢

速度很慢，YouTube 缓冲

① 切换「故障转移」或「负载均衡」模式
② 优先选择标注「专线」的节点
③ 晚高峰（20:00-23:00）换低延迟节点

📋

订阅链接导入失败

① 确认复制的是完整链接（以 https:// 开头）
② 检查客户端版本，旧版本不支持新格式
③ 尝试使用「扫码」方式代替粘贴

🌐

开了代理但 Netflix 看不了

① 选择标注「Netflix/流媒体解锁」的节点
② 使用「规则模式」而非「全局」避免检测
③ 部分机场仅高级套餐支持流媒体解锁

📱

iPhone 找不到 Shadowrocket

① Shadowrocket 需要美区 Apple ID 才能下载
② 可注册新 Apple ID 选美国，不填信用卡
③ 也可选用免费的 ClashMi 客户端替代

💻

Clash Verge 打开后无法上网

① 检查「系统代理」是否已开启
② 确认防火墙/安全软件未拦截 Clash
③ 尝试关闭 TUN 模式后重新连接
