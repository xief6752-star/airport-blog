前置知识：订阅链接是什么

订阅链接是机场提供的一个特殊 URL，形如：

https://api.example.com/link/abcd1234efgh5678?sub=clash

它包含了你账户的所有节点信息。客户端通过这个链接定期获取最新的节点配置，所以你不用手动更新。

⚠️ 注意
订阅链接等同于你的账户密码，千万不要分享给别人，也不要贴在公共地方。

第一步：从机场后台获取订阅链接

所有主流机场都支持生成订阅链接。步骤都差不多：

1登录机场官网账户
2找到"订阅链接"、"Clash 订阅"或"配置链接"菜单（通常在用户面板 → 服务 → 订阅）
3选择"Clash"格式（iOS Shadowrocket 也用 Clash 格式）
4点击"复制"或"获取链接"

如果机场后台没有找到订阅选项，可以：

  • 查看机场的使用文档或 FAQ
  • 联系机场客服问链接怎么获取
  • 有些机场需要开通某个套餐才能获取订阅链接

Clash / Clash Verge 客户端

Windows / Mac 上最流行的客户端。

1打开 Clash 客户端
在左侧找到"配置"或"Profiles"选项卡
2点击右侧上方的"+"按钮或"Download"
3粘贴你从机场后台复制的订阅链接
4点击"下载"、"导入"或"Confirm"
💡 提示
Clash 导入成功后，会在配置列表中显示一条新项。点击激活后，状态栏会变绿表示已连接。

iOS Shadowrocket 客户端

iPad / iPhone 上最常用的客户端。

1打开 Shadowrocket 应用
2点击底部"配置"标签
3点击右上角的"+"按钮
4选择"URL"，粘贴订阅链接
5点击"完成"，然后点击配置项的"下载"图标更新

ClashX（苹果 Mac）

1打开菜单栏的 ClashX 图标
2选择"配置" → "管理"
3点击左下角"+"，选择"从剪贴板导入"
（或者粘贴链接后点击"URL"）
4导入完成后点击"使用"激活

常见错误和解决方案

❌ "链接无效" / "配置错误"
原因：链接复制有误，或者格式不对
解决：重新从机场后台复制链接，确保没有多余空格。如果机场后台有多个格式（v2ray、Clash 等），一定要选 Clash 格式。
❌ "节点为空" / "没有可用的节点"
原因：账户过期了，或者套餐里确实没有节点
解决：检查机场账户的套餐是否还活跃，流量是否用完。如果都没问题，可能是机场服务器故障，稍后重试。
❌ "无法连接" / "连接超时"
原因：节点被封禁，或者你的网络环境特殊
解决：尝试换个节点，或者等待。如果一直不行，联系机场客服检查账户状态。
❌ "订阅失败" / "无法更新"
原因：客户端网络问题，或机场服务器暂时不可用
解决：检查网络连接，重启客户端，或者手动点"更新订阅"按钮。通常过几分钟就能恢复。

安全建议

✅ 你应该做的

  • 定期更换订阅链接：机场通常允许重新生成链接。如果感觉账户可能被泄露，立刻生成新链接。
  • 在有网络的地方更新订阅：订阅更新时链接会被发送到机场服务器，确保你在自己信任的网络上操作。
  • 检查客户端权限：客户端会拦截所有网络流量，确保你用的是官方版本，不要从不明来源下载。

❌ 你不应该做的

  • 不要分享订阅链接：即使是最亲近的人，分享链接就等于分享账户密码。
  • 不要贴在社群里：即使脱敏处理（比如改成 xxx），聪明人也能破译。
  • 不要相信"转卖账户"：有些人会兜售他人账户的订阅链接，这是高风险行为。
